# Flagship v2: image-generation briefs

For every ESSENTIAL and HIGH-IMPACT illustration in `ASSET_WISHLIST.md`, written to the standard of THE LAST STAND's
approved N1/N2 briefs. **Nothing has been generated.** Generate them from the original character sessions, approve
them, and they drop into `film/assets/` with no code change (each id is already a placeholder in the animatic).

## Common requirements

- **Reference:** the canonical kit card named in each brief (`asset-pack/sumi/avatars/cards/`), attached as the
  identity and style reference. Same painter's hand: ink linework with dry-brush texture, washed colour, warm paper
  grain, the same line weight and value structure as the card.
- **Identity:** the face must be the card's face (proportions, eye shape, scars, hair, markings), so a cut from the
  card to the new pose doesn't jump. The costume, palette, props and proportions are the card's. Add nothing: no new
  jewellery, armour, wounds or blood.
- **Ground (characters):** flat, uniform warm paper (close to `#efe7d8`), light grain only, or transparent PNG.
  **No ink disc, splatter, speed lines, slash, frame, crest, text, kanji or logo.** Those are animation layers.
- **Edges:** the figure fully separated, clean, unblurred; hair, fingers and cloth ends inside the canvas with ≥4%
  margin, unless the brief lets the body leave at the bottom.
- **Character canvas:** portrait 3:4, **2304×3072 or larger** unless stated.
- **Environments:** sumi-e landscape in the cast's hand: ink washes on warm paper, dry-brush edges, value only (warm
  black to paper), **no colour and no vermilion**. Not photographic, not 3D, not a fantasy matte painting. No torii,
  temples, castles, pagodas, cherry blossom, banners, flags, lanterns or legible marks (SHARED-RULES cliché list).
  Each layer a separate transparent PNG, larger than the frame so it can scale without showing edges.
- **Deliver** 2–3 seeds per brief, side by side with the card.
